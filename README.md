# People Counter — подсчёт людей на фото и видео

Курсовой проект на Python для обнаружения людей на фото и подсчёта уникальных людей за весь видеоролик. На фото программа будет отмечать людей рамками и сохранять результат. На видео она будет отслеживать людей между кадрами, чтобы не считать одного и того же человека на каждом кадре.

## Что уже есть

В проекте есть файл весов `models/yolo26s.pt`, список зависимостей и заготовки Python-модулей. Детектор пока не подключён, поэтому приложение ещё не готово к запуску.

## План разработки

1. Обработать одну фотографию: найти людей с помощью YOLO26s, вывести число в ui интерфейс и сохранить размеченную копию.
2. Добавить обработку видео: присваивать людям ID треков и учитывать каждый ID один раз за ролик.
3. Сделать окно на Tkinter для выбора файла и просмотра результата.

Подсчёт по ID даёт оценку числа людей. Если человек надолго пропадёт из кадра и вернётся, трекер может выдать ему новый ID. Повторное сопоставление таких треков (ReID) — отдельный этап.

## Стек

- **Python** — логика приложения.
- **Ultralytics / YOLO26s** — обнаружение людей.
- **OpenCV** — чтение и обработка фото и видео, рисование рамок.
- **Tkinter и Pillow** — интерфейс и показ изображений.

Зависимости перечислены в [`requirements.txt`](requirements.txt).
